# 内天山—七河地区青铜时代景观考古课程论文项目

景观考古学课程论文全套材料：选题论证、论文正文、Tableau 遗址数据库与可视化方案、参考文献。

## 目录导览

| 文件 | 内容 |
| --- | --- |
| `docs/01_选题评估与研究设计.md` | 初步选题评估、优化后的选题（"垂直景观与季节性流动"）、核心研究问题与调整理由 |
| `paper/论文_垂直景观与季节性流动.md` | 课程论文正文（约 9000 字，含摘要、理论、分析、讨论、结论与引用文献） |
| `data/sites_database.csv` | 34 处遗址数据库（坐标、海拔、生态带、类型、分期、生业证据），可直接导入 Tableau |
| `data/数据字典.md` | 数据库字段定义与使用注意（坐标精度、断代依据等） |
| `docs/02_Tableau可视化方案.md` | 4 套图表方案与仪表板建议（图 1 分布图为论文核心地图），含操作步骤 |
| `docs/03_参考文献清单.md` | 英/俄/中三语分级参考文献（原始报告优先）与检索建议 |

## 快速开始（Tableau）

1. 打开 Tableau，连接 → 文本文件 → 选择 `data/sites_database.csv`。
2. 将 `Latitude`/`Longitude` 设为地理角色"纬度/经度"。
3. 按 `docs/02_Tableau可视化方案.md` 制作图 1（遗址分布与功能—生态带结构图）。

## 重要提示

数据库坐标为文献汇编（精度等级见 `Coordinate Precision` 字段），用于区域尺度制图；提交论文前建议按数据字典的说明逐条回核关键遗址的原始报告。
