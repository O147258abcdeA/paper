# 内天山—七河地区青铜时代景观考古课程论文项目

景观考古学课程论文全套材料：选题论证、论文正文、Tableau 遗址数据库与可视化方案、参考文献。

本项目的研究重心已调整为：**跨生态带资源组织与山地生业体系**。论文不再以证明“是否农牧结合”为主要目标，而是在 Begash、Tasbas、Aigyrzhal-2、Chap 等遗址既有研究基础上，讨论农业、畜牧、季节性移动以及河谷、山麓、高山草场、山口等不同生态带资源如何被组织起来。

## 快速开始（Tableau）

1. 打开 Tableau，连接 → 文本文件 → 选择 `data/sites_database.csv`。
2. 将 `Latitude` / `Longitude` 设为地理角色“纬度/经度”。
3. 按 `docs/02_Tableau可视化方案.md` 制作图 1（遗址与生态带分布图）、图 2（生态带—遗址功能矩阵）和图 3（关键遗址资源组合图）。

## 重要提示

数据库坐标为文献汇编（精度等级见 `Coordinate Precision` 字段），用于课程论文层级的区域观察。提交论文前建议按数据字典说明逐条回核关键遗址的原始报告，尤其是 Begash、Tasbas、Aigyrzhal-2、Chap、阿敦乔鲁等核心材料。
