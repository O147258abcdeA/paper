# 选题评估与研究设计优化

## 一、对初步选题的评估

**初步选题：** 以内天山—七河地区青铜时代遗址为对象，从景观考古学视角讨论不同生态带（河谷、山麓、高山草场等）之间的资源利用、生业组织与空间结构关系。

### 优点

1. **与现有研究高度衔接。** 选题直接承接你在中亚青铜时代生业模式、内天山—七河人地关系与跨生态带资源利用方面的积累，材料熟悉度高，课程论文可直接转化为学位论文章节或期刊论文。
2. **区域选择恰当。** 内天山—七河地区是近十五年中亚青铜时代研究最活跃的区域之一：Begash、Tasbas、Dali（七河/准噶尔阿拉套）、Aigyrzhal-2、Chap、Uch-Kurbu（内天山）等系统发掘遗址提供了高质量浮选、测年与同位素数据，并已形成"内亚山地廊道"（Inner Asian Mountain Corridor, IAMC）这一可对话的理论框架。
3. **天然适合景观考古与可视化。** 山地垂直生态分带使"海拔"成为可量化、可制图的核心分析变量，与 Tableau 的地图与统计图表能力高度匹配。

### 不足

1. **问题域过宽。**"资源利用、生业组织与空间结构关系"实际上是三个问题，课程论文篇幅内难以同时充分展开，容易写成区域综述而非问题驱动的研究。
2. **"生态带"作为静态分类的局限。** 若仅按河谷/山麓/高山草场给遗址贴标签做分布统计，分析停留在描述层面；景观考古学的核心恰恰是人对景观的结构化实践（routine、movement、taskscape），需要一个能把"分带"转译为"实践"的中介概念。
3. **可检验性不足。** 未事先设定可用数据回答的具体问题，Tableau 分析容易沦为配图而非论证环节。

## 二、优化后的选题（建议采用）

**题目：** 《垂直景观与季节性流动：内天山—七河地区青铜时代遗址的海拔结构与生业组织》

**核心调整：以"垂直性（verticality）"为单一分析主轴**，把原来并列的三个问题收拢为一条因果链：

> 垂直生态梯度（环境结构）→ 遗址的海拔/生态带选址与功能分异（空间结构）→ 季节性垂直流动与农牧结合的生业组织（实践结构）。

### 调整理由

1. **概念聚焦。** "垂直性"是山地景观考古的经典议题（安第斯"垂直群岛"模式、阿尔卑斯季节性垂直放牧研究均可对话），既有理论纵深，又能与 Frachetti 的"非一致性制度"（nonuniform institutional complexity）和 IAMC 框架直接衔接，使论文具备国际对话面。
2. **变量可操作。** 海拔是每个遗址都能获得的连续变量，且与生态带、积温、生长季、牧草季节可用性稳定相关；以海拔为轴可以把"跨生态带资源利用"转化为可制图、可统计的问题，而不依赖难以获取的逐遗址植物/动物定量数据。
3. **完美匹配 Tableau。** 海拔—功能散点图、分海拔段的遗址类型构成、分布地图三者构成一个完整论证链，地图不再是配图而是证据。
4. **发展潜力。** 课程论文验证"海拔结构"假说后，学位论文可向两个方向延伸：（a）加入植物考古/同位素数据检验季节性；（b）与博尔塔拉（阿敦乔鲁、呼斯塔）对比，做跨天山的比较景观研究——正好覆盖你"跨生态带资源利用"的长期兴趣。

## 三、核心研究问题

**总问题：** 内天山—七河地区青铜时代人群如何通过遗址选址与功能分异，把垂直生态梯度组织进其生业系统？

分解为三个可用数据库回答的子问题：

- **Q1（海拔结构）：** 不同功能类别的遗址（居址、墓葬、岩画）在海拔与生态带上是否存在系统性分异？居址是否集中于冬季可居的中低海拔河谷—山麓带，而岩画等仪式性地点是否标记高海拔季节性牧场及通道？
- **Q2（生业—海拔关系）：** 出土作物（黍、小麦、大麦）与家畜构成是否随海拔变化？高海拔遗址（如 Tasbas、阿敦乔鲁约 1500–2500 m）的农业证据如何修正"高山=纯牧业"的传统假设？
- **Q3（通道与连通性）：** 遗址是否沿河谷与山口形成线性走廊？内天山与七河两个小区在海拔结构上的异同说明了何种区域组织差异？

## 四、研究设计

1. **建立遗址数据库**（30+ 处经发掘或系统调查的青铜时代遗址点），字段含坐标、海拔、生态带、遗址类型、分期、生业证据、数据来源（见 `data/`）。
2. **Tableau 分析**：分布图（按类型/生态带着色）、海拔—类型箱线/散点图、生业证据—海拔矩阵（见 `docs/02_Tableau可视化方案.md`）。
3. **景观考古阐释**：用 taskscape、季节性节律（seasonal round）、纪念性与路径（monumentality & movement）三个概念解读统计模式。
4. **论文写作**：见 `paper/论文_垂直景观与季节性流动.md`。

## 五、风险与对策

| 风险 | 对策 |
| --- | --- |
| 俄语老报告坐标不精确 | 数据库设"坐标精度"字段（精确/近似/谷地级），地图上以符号区分，统计仅用海拔（误差小） |
| 调查偏差（河谷调查多、高山调查少） | 在论文中明确讨论 taphonomy 与调查史偏差，结论限定为"已知遗址结构" |
| 生业数据仅部分遗址有 | Q2 仅用有浮选/动物考古报告的遗址子集，不外推 |
