# 选题评估与研究设计优化

## 一、重新判断问题重心

**调整后的选题判断：** 对内天山—七河地区青铜时代材料而言，论文最值得讨论的问题不再是“是否存在农牧结合经济”，而是**农作、畜牧、季节性移动以及河谷、山麓、高山草场等不同生态带资源如何被组织成一个山地生业体系**。

Begash、Tasbas、Aigyrzhal-2、Chap 等遗址的研究已经表明，青铜时代中亚山地人群并非单纯游牧者，作物利用与畜牧活动共存已基本成为共识。在既有研究确立农牧结合基础上，进一步探讨其组织机制，更能体现本文的推进空间。

本文因此将研究重心从“农牧结合经济”上移到“跨生态带资源组织”：

> 河谷、山麓、中山草场、高山草甸、山口与通道并不是同质背景，而是承担不同生计、交通与仪式功能的资源空间。问题在于，青铜时代山地人群如何在这些空间之间安排居住、耕作、放牧、埋葬、通行和仪式活动。

## 二、优化后的题目与核心概念

**建议题目：** 《跨生态带资源组织与山地生业体系：内天山—七河地区青铜时代遗址的景观考古学观察》

如需保留原题中的“垂直景观”表述，可用：

**备选题目：** 《垂直景观中的资源组织：内天山—七河地区青铜时代遗址的生态带功能与生业体系》

### 核心概念：跨生态带资源组织

“跨生态带资源组织”比“农牧结合”更适合作为论文主轴，因为它同时包含三层内容：

1. **资源类型**：作物、家畜、水源、耕地、牧场、山口、通道、仪式性地点。
2. **生态带差异**：河谷、山麓、中山草场、高山草甸、高位盆地与山口。
3. **组织方式**：居住节点、农牧复合节点、季节性移动路径、墓葬与岩画的空间分工。

在这个框架下，“农牧结合”不是结论本身，而是资源组织中的一类现象；真正需要解释的是这些资源如何在山地景观中被安排和连接。

为行文简洁，正文中可在首次说明后将“跨生态带资源组织”简称为“生态带资源整合”或“资源组织”，但题目和核心问题仍保留完整表述，以避免概念过窄。

## 三、核心研究问题

**总问题：** 青铜时代内天山—七河地区山地人群如何依托河谷、山麓与高山草场之间的生态差异，组织农业、畜牧与季节性移动？

可分解为三个子问题：

1. **生态带功能问题**  
   不同生态带在生业体系中分别承担什么功能？河谷是否主要承担居住、耕作、水源利用和冬季避风等功能？山麓是否是农牧混合与季节转换的重要地带？高山草场和山口是否更多关联夏季放牧、通行和仪式活动？

2. **关键遗址的资源组合问题**  
   Begash、Tasbas、Dali、Aigyrzhal-2、Chap、Uch-Kurbu 等遗址各自体现了怎样的资源组合？它们不应只被当作“出现农作物证据”的例子，而应被理解为不同生态位置上的资源节点。

3. **景观结构与组织方式问题**  
   山地垂直生态带的压缩分布是否降低了跨生态带利用成本？河谷—山麓—高山草场之间是否形成可反复利用的季节性路径？遗址分布是否反映资源节点之间的连接，而不仅是海拔差异？

## 四、材料组织方式

论文不宜先铺陈理论，再用遗址证明“垂直性”。更符合中国考古学论文的写法，是先展开关键遗址材料，再从材料中归纳景观组织。

### 1. 河谷—山麓居住与耕作节点

重点材料包括 Begash、Dali、Aigyrzhal-2、Uch-Kurbu。讨论重点不只是有无作物，而是它们与水源、避风环境、可耕地、冬春活动和河谷通道之间的关系。

### 2. 高地农牧复合节点

重点材料包括 Tasbas、Chap I/II、Turgen、Asy 高地材料。讨论重点是高地地点是否同时包含居住、作物利用、畜牧、加工、墓葬或仪式活动，而不是简单归入“夏牧场”或“高海拔农业”。

### 3. 高山草场、山口与仪式性地点

重点材料包括 Tamgaly、Kulzhabasy、Saimaluu-Tash、Juuku valley、Asy plateau petroglyphs。岩画材料可用于讨论高山草场、通道和季节性到访，但必须明确风格断代的限制。

### 4. 博尔塔拉比较材料

阿敦乔鲁、呼斯塔可作为跨天山比较材料，而不宜并入主体区域平行展开。它们的意义在于提示高位盆地和山口节点可能具有聚落、交通和交流的复合功能。

## 五、Tableau 分析设计

Tableau 的作用应从“证明海拔结构”调整为“观察生态带—功能—资源组合”。

### 图 1：遗址与生态带分布图

展示遗址与河谷、山麓、高山草场、山口之间的关系。该图用于说明遗址是否集中于资源节点，而不是仅显示点位位置。

### 图 2：生态带—遗址功能矩阵

以生态带为横轴，以遗址类型或活动证据为纵轴，观察居址、墓葬、岩画、作物、家畜证据在不同生态带中的组合关系。

### 图 3：关键遗址资源组合图

以 Begash、Tasbas、Dali、Aigyrzhal-2、Chap、Uch-Kurbu 等为行，以作物、羊/山羊、牛、马、墓葬、岩画、河谷位置、高山草场或山口位置等为列，显示不同遗址承担的资源功能。

### 图 4：河谷—山麓—高山草场剖面式示意图

作为概念图使用，展示不同生态带在山地生业体系中的可能分工：河谷与山麓承担居住、耕作、越冬和水源利用，高山草场承担夏季放牧，山口和岩画点联系通行与仪式活动。

## 六、论证逻辑

新的论证顺序为：

1. 内天山—七河地区具有明显的垂直生态带差异。
2. 不同生态带提供不同资源，并具有不同季节可利用性。
3. 青铜时代遗址并非随机分布，而是集中于河谷、山麓、高地草场和通道节点。
4. Begash、Tasbas、Chap、Aigyrzhal-2 等遗址显示农业和牧业不是简单并列，而是被安置在不同生态空间中。
5. 河谷、山麓、高山草场、山口之间可能构成互补性资源体系。
6. 景观考古学的价值在于解释这种资源组织方式，而不是单纯给海拔差异命名。

## 七、风险与对策

| 风险 | 对策 |
| --- | --- |
| 论证重新滑回“是否农牧结合” | 在绪论和结论中明确：农牧结合是前提，资源组织是问题 |
| Tableau 分析仍停留在海拔统计 | 增加生态带—功能矩阵和关键遗址资源组合图 |
| 关键遗址材料不足 | 扩展 Begash、Tasbas、Aigyrzhal-2、Chap 的个案讨论，使其成为论证主体 |
| 岩画断代不确定 | 只作为通道、草场和仪式活动的提示性材料，不作强证据 |
| 缺少一手科技数据 | 明确本文为文献汇编与课程层面的景观观察，结论使用“提示”“可能”等谨慎表述 |
