# Tableau 地图与可视化方案

数据源：`data/sites_database.csv`（UTF-8，含 BOM 兼容版本可由 Excel 另存）。导入 Tableau 后，将 `Latitude` / `Longitude` 字段设为地理角色“纬度/经度”。

本方案的目标已从单纯展示“海拔结构”调整为观察**生态带—遗址功能—资源组合**之间的关系。海拔仍是重要变量，但不再作为论文唯一主轴；Tableau 图表应服务于“跨生态带资源组织”这一问题。

## 图 1（必做）：遗址与生态带分布图

- **类型：** 符号地图（Symbol Map）
- **做法：** `Longitude` → 列，`Latitude` → 行；`Site Type CN`（遗址类型）→ 形状；`Eco Zone CN`（生态带）→ 颜色；`Coordinate Precision` → 透明度或边框；`Subregion CN` → 筛选器。
- **底图：** 建议选择 “Outdoors” 或带地形晕渲的底图，以突出山地、河谷与高原。
- **论证作用：** 观察遗址是否集中于河谷、山麓、高山草场和山口附近，说明遗址分布与资源节点之间的关系。

## 图 2（核心）：生态带—遗址功能矩阵

- **类型：** 高亮表（Highlight Table）或堆叠条形图
- **做法：**
  - 行：`Eco Zone CN`
  - 列：`Site Type CN`
  - 颜色或大小：遗址数量
  - 可加入 `Subregion CN` 作为筛选器，分别观察七河、内天山和博尔塔拉比较材料。
- **可观察问题：**
  - 哪些生态带以居址或居址+墓葬为主？
  - 岩画是否更集中于高山草场、山口或通道地带？
  - 高地遗址是否只对应岩画，还是也存在居址和农牧活动？
- **论证作用：** 将“不同生态带承担不同功能”可视化，避免分析退回单纯海拔高低。

## 图 3（核心）：关键遗址资源组合图

- **类型：** 点阵图、热力矩阵或高亮表
- **筛选对象：** Begash、Dali、Tasbas、Aigyrzhal-2、Chap I、Chap II、Uch-Kurbu、Turgen-2、Asy-Saga、Tamgaly、Kulzhabasy、Saimaluu-Tash、Adunqiaolu、Husta。
- **做法：**
  - 行：`Site Name CN`
  - 列：资源或活动字段，如 `Millet`、`Wheat`、`Barley`、`Sheep-Goat`、`Cattle`、`Horse`、`Site Type CN`、`Eco Zone CN`
  - 颜色：有 / 无 / 不明
  - 排序：不按海拔机械排序，可按“河谷—山麓—中山—高山草场—山口比较材料”的解释顺序排列。
- **论证作用：** 展示关键遗址不是同一类“农牧结合证据”，而是不同生态位置上的资源组合节点。
- **写作提示：** 对 Begash、Tasbas、Aigyrzhal-2、Chap 等遗址应结合正文个案讨论解释，图表只作材料组织辅助。

## 图 4（辅助）：生业证据—生态带分布图

- **类型：** 分面散点图或气泡图
- **做法：**
  - 横轴：`Eco Zone CN`
  - 纵轴：`Elevation m`
  - 颜色：作物证据（可将 `Millet`、`Wheat`、`Barley` 汇总为“作物有/无”）
  - 形状：家畜证据或遗址类型
- **论证作用：** 观察作物与家畜证据在不同生态带中的分布，讨论农业、牧业是否被安排在不同空间节点中。
- **注意：** 不宜据此直接判断种植地点，除非原始报告有明确本地种植、加工工具或同位素证据。

## 图 5（可选）：河谷—山麓—高山草场剖面式示意图

- **类型：** 概念性剖面图或示意仪表板
- **做法一：** 使用 `Elevation m` 为纵向轴，以生态带顺序排列遗址点。
- **做法二：** 在 Tableau 仪表板中组合地图、生态带矩阵和资源组合图，形成从低地到高地的解释性展示。
- **论证作用：** 展示河谷、山麓、中山、高山草场与山口在生业体系中的可能分工。
- **说明：** 该图是解释性示意，不是严格地形剖面；若发展为正式研究，应转入 GIS 制作真实地形剖面和成本路径分析。

## 仪表板建议

建议将图 1、图 2、图 3 组合为一个交互仪表板：

1. 地图作为主视图。
2. 点击某一生态带或遗址类型时，联动过滤资源组合图。
3. 使用 `Subregion CN` 和 `Period` 作为全局筛选器。
4. 在图注中标明坐标精度和数据来源。

该仪表板的展示重点应是：

> 青铜时代遗址如何分布在不同生态带和资源节点上，以及这些节点如何共同构成山地生业体系。

## 操作提示

1. 经纬度为十进制度（WGS84），Tableau 通常可自动识别；若点位偏移，检查地理角色设置。
2. `Elevation m` 设为连续度量；生态带比较时优先使用 `Eco Zone CN`，避免只按绝对海拔解释。
3. 如需建立作物汇总字段，可设置计算字段：`IF [Millet]="Yes" OR [Wheat]="Yes" OR [Barley]="Yes" THEN "有作物证据" ELSE "无或不明" END`。
4. 如需建立家畜汇总字段，可设置计算字段：`IF [Sheep-Goat]="Yes" OR [Cattle]="Yes" OR [Horse]="Yes" THEN "有家畜证据" ELSE "无或不明" END`。
5. 导出论文用图时，建议固定仪表板尺寸（如 1600×1000），中文字体使用思源黑体或微软雅黑。
6. 所有图均应注明：数据为文献汇编，部分坐标为近似或谷地级定位，岩画断代存在风格学限制。
