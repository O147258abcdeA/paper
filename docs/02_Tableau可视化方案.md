# Tableau 地图与可视化方案

数据源：`data/sites_database.csv`（UTF-8，含 BOM 兼容版本可由 Excel 另存）。导入 Tableau 后将 `Latitude`/`Longitude` 字段设为地理角色"纬度/经度"。

## 核心地图（满足课程"至少 1 幅地图"要求，建议做图 1 + 图 2）

### 图 1（必做）：遗址分布与功能—生态带结构图

- **类型：** 符号地图（Symbol Map）
- **做法：** `Longitude`→列，`Latitude`→行；`Site Type CN`（遗址类型）→形状（居址=方、墓葬=圆、岩画=三角）；`Eco Zone CN`（生态带）→颜色（河谷绿、山麓黄、中山褐、高山草场蓝）；`Elevation m`→大小（可选）；`Coordinate Precision`→边框或透明度以区分坐标精度。
- **底图：** 地图层选 "Outdoors"（带地形晕渲），最能呈现山地垂直结构。
- **论证作用：** 一图同时回答 Q1（功能分异）与 Q3（沿河谷/廊道的线性分布），是论文的核心证据图。

### 图 2（强烈建议）：海拔—遗址类型分异图

- **类型：** 箱线图或抖动散点图（非地图，但为论文统计核心）
- **做法：** `Site Type CN`→列，`Elevation m`→行（取消聚合，显示散点），叠加箱线图；`Subregion CN`（七河/内天山）→颜色或分面。
- **论证作用：** 直接检验 Q1 的"海拔结构"假说：岩画/季节性营地中位海拔显著高于长期居址。

## 进阶可视化（提升论文与答辩效果）

### 图 3：生业证据—海拔矩阵

- **类型：** 高亮表（Highlight Table）或甘特/点阵图
- **做法：** 仅筛选 `Has Botanical Data = Yes` 的遗址；行=遗址（按 `Elevation m` 降序排序），列=作物/家畜字段（`Millet`、`Wheat`、`Barley`、`Sheep/Goat`、`Cattle`、`Horse`），有/无以颜色填充。
- **论证作用：** 回答 Q2——展示黍、麦类在 2000 m 以上遗址（Tasbas、Chap、阿敦乔鲁）的出现，反驳"高山纯牧业"假设。

### 图 4：分期—海拔动态图

- **类型：** 地图 + `Period`（分期：早/中/晚青铜）作筛选器或"页面"（Pages）做成动画；或散点图 `Period`→列、`Elevation m`→行。
- **论证作用：** 显示晚青铜阶段遗址向高海拔扩展（如有），把静态景观转为历时过程。

### 仪表板（Dashboard）建议

将图 1–3 组合为一个交互仪表板：地图为主视图，点选生态带或遗址类型时联动过滤箱线图与生业矩阵；加入 `Subregion` 与 `Period` 全局筛选器。课程展示时可现场交互，效果远好于静态图。

## 操作提示

1. 经纬度为十进制度（WGS84），Tableau 自动识别；若地图点位偏移，检查字段地理角色设置。
2. `Elevation m` 设为连续度量；分海拔段可建计算字段：`IF [Elevation m] < 1200 THEN "河谷低地(<1200)" ELSEIF [Elevation m] < 1800 THEN "山麓(1200–1800)" ELSEIF [Elevation m] < 2400 THEN "中山(1800–2400)" ELSE "高山(≥2400)" END`。
3. 导出论文用图：仪表板 → 设定固定尺寸（如 1600×1000）→ "工作表/仪表板 → 导出 → 图像"，注意中文字体选思源黑体或微软雅黑以免乱码。
4. 地图务必加：图例、比例尺（Tableau 地图选项中开启）、坐标精度说明、数据来源注记。
