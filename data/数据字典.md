# 数据字典（sites_database.csv）

数据库收录内天山—七河地区（含新疆博尔塔拉对比亚区）经发掘或系统调查的青铜时代遗址。坐标系 WGS84，十进制度。编码 UTF-8。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| Site ID | 文本 | 唯一编号（亚区缩写+序号：ZH=七河，IT=内天山，BT=博尔塔拉） |
| Site Name | 文本 | 通用英文/转写名 |
| Site Name CN | 文本 | 中文名 |
| Latitude | 数值 | 纬度（十进制度，WGS84） |
| Longitude | 数值 | 经度（十进制度，WGS84） |
| Coordinate Precision | 文本 | Exact（发表坐标）/ Approximate（依文献描述与地图复原，±数公里）/ Valley（仅定位到谷地） |
| Elevation m | 整数 | 海拔（米），来源于发表数据或依坐标从 DEM/地形图读取 |
| Eco Zone | 文本 | 生态带：Valley-oasis / Foothill-steppe / Mid-mountain / Alpine-meadow |
| Eco Zone CN | 文本 | 生态带中文：河谷绿洲 / 山麓草原 / 中山带 / 高山草甸 |
| Subregion | 文本 | Zhetysu / Inner Tian Shan / Bortala |
| Subregion CN | 文本 | 七河 / 内天山 / 博尔塔拉 |
| Country | 文本 | KZ / KG / CN |
| Site Type | 文本 | Settlement / Burial / Rock art / Settlement+Burial |
| Site Type CN | 文本 | 居址 / 墓葬 / 岩画 / 居址+墓葬 |
| Period | 文本 | 分期（EBA 早青铜 / MBA 中青铜 / LBA 晚青铜，可复合） |
| Dating Basis | 文本 | C14（碳十四）/ Typology（类型学）/ Style（岩画风格） |
| Has Botanical Data | 文本 | Yes/No——是否有浮选/植物考古发表数据 |
| Millet / Wheat / Barley | 文本 | Yes / No / n.d.（无数据）——该作物是否见于遗址 |
| Sheep-Goat / Cattle / Horse | 文本 | Yes / No / n.d.——动物考古证据 |
| Key Reference | 文本 | 核心参考文献（短引，全引见 docs/03_参考文献清单.md） |
| Notes | 文本 | 备注（功能判断、季节性、特殊发现等） |

## 使用注意

1. **坐标精度**：Approximate 与 Valley 级坐标仅用于区域尺度制图，不可用于遗址尺度分析；在 Tableau 中以 `Coordinate Precision` 区分符号透明度或边框。
2. **海拔**：相对坐标误差更稳健（谷地内海拔变化小），是统计分析的首选变量。
3. **岩画断代**：Style 断代的岩画点收录标准为"学界公认含显著青铜时代图层"，分析时可用 `Dating Basis` 筛选敏感性检验。
4. **生业字段**：n.d. ≠ No；图 3 类分析须先筛 `Has Botanical Data = Yes`。
5. 数据为文献汇编，用于课程论文层级的区域分析；如发展为正式研究，须逐条回核原始报告并补充 DEM 提取的精确海拔。
